# 🏎️ Neon Racer ULTIMETE

Um jogo de corrida arcade futurista desenvolvido em HTML5, CSS3 e JavaScript puro, inspirado em clássicos como Need for Speed, Subway Surfers e jogos neon cyberpunk.

O jogador controla um carro estilo Fórmula 1 em alta velocidade, desviando de obstáculos, coletando moedas e power-ups enquanto a dificuldade aumenta progressivamente.

---

## ✨ Recursos do jogo

* 🚗 Carro estilo F1 com visual neon
* 🎮 Controles para teclado e touch/mobile
* ⚡ Sistema de Nitro com aumento de velocidade
* 🛡️ Escudo de proteção
* 🪙 Sistema de moedas/coins
* 🌤️ Sistema dinâmico de clima:

  * Chuva
  * Neve
  * Neblina
  * Céu limpo
* 🌙 Ciclo Dia e Noite automático
* 🎵 Música de fundo + efeitos sonoros
* 🏆 Sistema de recorde salvo no navegador
* 🚘 Garagem com troca de cores do carro
* 📱 Design responsivo para celular
* ✨ Efeitos neon, glow e animações suaves
* ☁️ Compartilhamento de pontuação

---

## 🛠️ Tecnologias utilizadas

* HTML5 Canvas
* CSS3
* JavaScript Vanilla

* LocalStorage

---

## 🎮 Como jogar

### Computador

* A / ← = mover para esquerda
* D / → = mover para direita
* P = pausar
* R = reiniciar

### Celular

* Toque no lado esquerdo da tela para mover à esquerda
* Toque no lado direito para mover à direita

---

## ⚡ Power-ups

### Nitro

Aumenta drasticamente a velocidade do carro temporariamente.

### Escudo

Protege contra uma colisão.

---

## 🏆 Objetivo

Sobreviva o máximo possível, desvie dos carros, colete moedas e tente bater seu recorde.
